# CMA Exam Master — starter website

A responsive static website starter for accounting learners. It includes:
- Responsive homepage and mobile navigation
- Subject cards with search
- Interactive multiple-choice quizzes with instant feedback and explanations
- Score tracking, previous/next navigation, and restart
- Basic SEO metadata, canonical URL placeholder, robots.txt and sitemap.xml

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. The core website works as a static site.
3. For the best testing experience, use a local server such as VS Code Live Server.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named `cma-exam-master` (or another name).
3. Upload `index.html`, `styles.css`, `app.js`, `robots.txt`, and `sitemap.xml` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. GitHub will show the public URL, usually `https://YOUR-USERNAME.github.io/cma-exam-master/`.
7. Replace `YOUR-SITE-URL.example` in `index.html`, `robots.txt`, and `sitemap.xml` with the real URL. For a project URL, include the repository path, e.g. `https://YOUR-USERNAME.github.io/cma-exam-master/`.
8. Commit the changes and wait for the site to redeploy.

## Help Google discover the site
1. Open Google Search Console and add the deployed URL as a URL-prefix property.
2. Verify ownership using one of the offered methods.
3. Submit the sitemap URL, e.g. `https://YOUR-USERNAME.github.io/cma-exam-master/sitemap.xml`.
4. Use URL Inspection to request indexing of the homepage.
5. Ensure the website is public, useful, mobile-friendly, and does not block crawlers.

Indexing is not instant or guaranteed. Appearing in Google Search also depends on content quality, competition, links, and other factors.

## Before launch
- Replace the canonical URL and sitemap placeholders.
- Check every question and answer against the current syllabus and reliable references.
- Add original chapter notes and more question sets.
- Add a contact/privacy page before collecting any personal information.
- This starter does not include user accounts, a database, cloud progress sync, or a content management system. Quiz progress is kept only in the current page session.
- The sample quiz questions are educational examples, not official answer keys. Review law and tax content for current applicability.

## Files
- `index.html` — homepage and page structure
- `styles.css` — responsive styling
- `app.js` — subject search and quiz functionality
- `robots.txt` — crawler instructions
- `sitemap.xml` — sitemap template
